### 💡 Task 2: Sensor-Based Simulation — Automatic Night Light System
* **Directory:** [`/TASK-2-SENSOR-SIMULATION`](./TASK-2-SENSOR-SIMULATION)
* **Simulation Platform:** Tinkercad Circuits
* **Microcontroller:** Arduino Uno R3
* **Components:** LDR (Photoresistor), $10\text{ k}\Omega$ Resistor, LED, $220\ \Omega$ Resistor, Breadboard
* **Description:** Circuit design and C++ embedded software for an automated light detection system. Reads analog ambient light data via a voltage divider network and dynamically controls an LED light source based on a calibrated light threshold.
